## 🚀 How to Run the Projects

1. Clone this repository:

   ```bash
   git clone https://github.com/ASamasha/codealpha_tasks.git
   ```

2. Navigate to the project directory:

   ```bash
   cd codealpha_tasks
   ```

3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter nltk textblob
   ```

   Install only the additional libraries required by each notebook.

4. Open the notebooks using Jupyter Notebook or Google Colab.

Datasets
